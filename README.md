# Unplugged
A smart alarm clock with a custom UI that uses music as the alarm 

## Why I Built Unplugged
- I do not sleep with my phone in my room
- The sound of alarms triggers me
- I wanted to wake up to music instead of a blaring alarm
## Problem
- No clock has locally downloaded music - a phone is required to wake up to music
## Features
- Custom UI
- Local songs (and playlists) to choose how to wake up
- MP3 Player feature where the clock can play music regardless of when the alarm goes off

## Tools Used
- Fusion360
- Arduino IDE

## How to Use
Press the buttons to set an alarm and set a playlist to act as the sound - 4 buttons (Up, Down, Select, Back)
## Results
I use the clock every single morning and wake up to music
## Future Improvements
- use a higher-quality RTC so the time stays more accurate (currently the clock moves one minute ahead every month)
- PCB instead of a clump of wires
